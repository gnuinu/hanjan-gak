# 한잔각 (hanjan-gak)

한잔각은 인원과 모임 성격을 설정한 뒤 바로 즐길 수 있는 술자리·모임용 랜덤 미니게임 웹 애플리케이션입니다. 한 대의 기기를 함께 보며 진행하는 pass-and-play 방식으로 설계했습니다.

친구 모임과 커플 모임을 지원하며, 음주 없이도 사용할 수 있도록 음주 무관 모드를 제공합니다.

## 주요 기능

- 2~12명이 함께 즐길 수 있는 9종의 미니게임을 제공합니다.
- 친구끼리·커플끼리 모드에 따라 게임과 벌칙을 구분합니다.
- 벌칙 수위를 순함·보통·매움으로 선택할 수 있습니다.
- 음주 관련 벌칙을 제외하는 음주 무관 모드를 제공합니다.
- 소리, 진동, 화면 유지, 경마 지목 모드를 설정할 수 있습니다.
- 사용자가 직접 벌칙을 추가하고 삭제할 수 있습니다.
- PWA를 지원하므로 모바일 기기에 설치하여 사용할 수 있습니다.

## 게임 목록

| 게임 | 방식 | 인원 |
| --- | --- | --- |
| 경마 | 말의 순위를 겨루어 꼴찌를 정합니다. 지목 모드에서는 1등이 대상자를 선택합니다. | 2~12명 |
| 손가락 룰렛 | 모두 화면에 손가락을 올린 뒤 무작위로 대상자를 정합니다. | 2~10명 |
| 폭탄 카드 | 카드를 한 장씩 뒤집다가 폭탄 카드를 뽑은 사람이 대상이 됩니다. | 2~12명 |
| 반응 속도 | 신호가 나타난 뒤 가장 늦게 반응한 사람을 정합니다. 멀티터치가 필요합니다. | 2~12명 |
| 룰렛 | 간단한 룰렛으로 무작위 대상자를 정합니다. | 2~12명 |
| 텔레파시 | 같은 선택을 한 다수와 다른 선택을 한 소수파를 가립니다. | 2~12명 |
| 깔때기 | 가장 먼저 출구에 도착한 대상을 정합니다. | 2~12명 |
| 눈치게임 | 한 키보드를 공유해 숫자를 입력합니다. 같은 숫자를 입력한 참여자가 대상이 됩니다. | 3~8명 |
| 커플 밸런스 | 서로의 선택을 맞히는 커플 전용 게임입니다. | 2명 |

### 이번 업데이트

경마 게임을 심야 경마장 장면으로 개선했습니다. 관중석, 조명탑, 달리는 말 애니메이션과 속도에 따른 흙먼지 효과를 추가했으며, 인원이 많을 때에는 레인 높이를 자동으로 조정해 최대 12명까지 안정적으로 표시합니다. 8명을 초과하면 장면 요소를 간소화해 게임 정보를 더 명확하게 보여 줍니다.

## 실행 방법

```bash
npm install
npm run dev
```

다른 명령은 다음과 같습니다.

```bash
npm test         # Vitest 테스트를 실행합니다.
npm run build    # 타입 검사 후 배포용 파일을 생성합니다.
npm run preview  # 생성된 배포 파일을 로컬에서 미리 봅니다.
```

## 사용 안내

1. 참여자 수와 이름을 입력합니다.
2. 필요하다면 설정에서 모임 성격, 벌칙 수위, 음주 무관 모드 등을 조정합니다.
3. 게임을 선택해 진행합니다.
4. 게임 결과에 따라 벌칙을 뽑습니다.

매움 단계의 벌칙은 언제든 거부할 수 있으며, 거부 시에는 한 잔으로 대체합니다. 음주가 부담스러운 자리에서는 음주 무관 모드를 사용해 주시기 바랍니다.

## 프로젝트 구조

```text
src/
├─ domain/       게임 규칙, 타입, 난수 및 벌칙 처리 로직
├─ games/        개별 미니게임 모듈과 테스트
├─ shell/        참여자 설정, 게임 선택, 결과 및 통계 화면
├─ store/        Zustand 기반 세션 및 라운드 상태 관리
├─ ui/           공통 UI 컴포넌트와 피드백 기능
├─ data/         기본 벌칙과 게임 주제 데이터
└─ styles/       전역 스타일과 디자인 토큰
```

참여자, 설정, 사용자 추가 벌칙은 브라우저의 `localStorage`에 저장합니다. 게임 기록은 현재 모임 동안에만 유지합니다.

## 배포

기본 빌드 경로는 GitHub Pages 프로젝트 사이트용 `/hanjan-gak/`입니다.

```bash
npm run build                 # GitHub Pages용
BASE_PATH=/ npm run build     # 도메인 루트 배포용
```

Cloudflare Pages, Netlify, Vercel 등 도메인 루트에서 제공하는 환경에서는 `BASE_PATH`를 `/`로 설정합니다. Netlify는 저장소의 `netlify.toml`에 해당 설정이 포함되어 있습니다.

GitHub Pages는 저장소의 GitHub Actions 배포 워크플로를 사용하도록 설정합니다. 프로젝트 사이트의 기본 경로와 빌드 경로가 일치해야 정적 자산과 PWA가 정상적으로 동작합니다.
